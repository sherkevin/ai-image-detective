# 学生任务单：机器怎样判断图片相似

## 任务目标

完成本课后，你需要能解释：

1. 图片可以被表示成一组数字特征；
2. 相似度排序会受到特征权重影响；
3. 检索结果出错时，可能是表示、权重或任务目标不清楚。

## 任务 1：选择目标

打开 `index.html`，选择一张目标图形。

记录默认排序下最相似的 3 个结果。它们和目标相似在哪里？

## 任务 2：调整权重

分别把颜色、形状、纹理权重调到最高，观察排序变化。

填写：

- 颜色权重最高时，系统更关注什么？
- 形状权重最高时，系统更关注什么？
- 纹理权重最高时，系统更关注什么？

## 任务 3：解释误判

找一个你认为“不应该排这么前”的结果。

解释它为什么被系统排到前面：是颜色像、形状像，还是纹理像？

## 任务 4：改进策略

如果任务是“找同类图标”，你会提高哪个权重？

如果任务是“找同色素材”，你会提高哪个权重？

写下你的权重设置，并截图或记录排序结果。
