# 教师说明

## 课程定位

本项目适合用来解释“向量表示”和“相似度检索”。它不要求学生先学习线性代数，而是通过可视化权重和排序变化建立直觉。

## 推荐流程

1. 导入：展示两张图片，问学生“它们相似在哪里”。
2. 抽象：把颜色、形状、纹理写成特征。
3. 操作：学生选择目标图形，调节权重。
4. 讨论：同一个目标在不同权重下为什么有不同排序。
5. 复盘：引出真实 AI 中 embedding、nearest neighbor、推荐和多模态检索。

## 教学重点

- Feature：模型看到的是数字表示；
- Weight：任务目标不同，特征重要性不同；
- Similarity：相似度不是绝对真理，而是某种规则下的距离；
- Error analysis：误判要回到表示和目标，而不是只说模型不聪明。

## 分层拓展

- 基础任务：描述最相似结果的共同点；
- 进阶任务：通过调权重让指定结果排到第一；
- 挑战任务：设计一个新图形，并给它写出特征向量；
- 讨论任务：推荐系统为什么会反复推荐相似内容。
