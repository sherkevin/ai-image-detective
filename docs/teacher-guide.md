# 教师指南：图像检索项目

本项目适合用来解释“向量表示”和“相似度检索”。它不要求学习者先学习线性代数，而是通过可视化权重和排序变化建立直觉。

## 建议流程

1. 导入：展示两张图片，问学习者“它们相似在哪里”。
2. 拆解：把颜色、边缘、形状转化为特征。
3. 操作：学习者选择目标图形，调节权重。
4. 讨论：为什么检索结果会变化，哪些相似是表面的。
5. 延伸：介绍图像向量和深度学习特征。

## 教师观察点

- 是否能解释特征向量中的每个维度。
- 是否能说明不同权重如何改变排序。
- 是否能从误判案例中提出改进方案。
- 是否能把手工特征自然连接到卷积神经网络和图文对齐模型特征。
