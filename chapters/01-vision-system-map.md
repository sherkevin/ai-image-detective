# 1. 视觉系统地图

图像智能系统不是简单地“识别图片”。在本课程中，一张图片会经历五个环节：

```text
图片输入 -> 特征提取 -> 向量表示 -> 相似度排序 -> 误判分析
```

这张系统地图会贯穿全书。每次实验都要回答三个问题：系统看见了什么，为什么认为两张图片相似，错在哪里。

## 五个核心部件

| 部件 | 作用 | 课堂可观察现象 |
| --- | --- | --- |
| 图片库 | 保存目标图片和候选图片 | 数据分布会影响检索结果 |
| 特征提取器 | 提取颜色、形状、纹理、边缘或模型特征 | 不同特征会关注不同相似性 |
| 向量表示 | 把图片变成数字列表 | 向量维度越清楚，解释越容易 |
| 检索器 | 按距离或相似度排序 | 权重改变会让排序改变 |
| 评价器 | 记录正确、误判和偏差 | 错误案例是改进系统的入口 |

## 课堂任务

选择 6-10 张图片，完成以下表格。

| 图片 | 颜色特征 | 形状特征 | 纹理特征 | 可能误判 |
| --- | --- | --- | --- | --- |
| | | | | |

然后选择一张目标图片，人工判断前三个最相似结果。进入互动实验室后，比较系统排序和人工排序是否一致。

## 教师备课提示

课堂正文只保留适合高中项目课的概念：像素、特征、向量、卷积、迁移学习和误判分析。教师备课时可以把复杂模型和工程材料作为背景知识，但课堂展示应始终回到可观察、可操作、可解释的任务。
