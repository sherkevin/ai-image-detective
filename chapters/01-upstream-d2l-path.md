# 1. 从 D2L 改造成高中视觉项目

D2L 的计算机视觉路线很完整，但高中课程不适合直接从深度学习全体系讲起。本章把 D2L 中与视觉项目最相关的章节拆出来，重排成一条更短、更可操作的项目路线。

## D2L 原始章节与本书改造

| D2L 章节 | 原始作用 | 高中化改造 |
| --- | --- | --- |
| 图像分类数据集 | 认识 Fashion-MNIST、标签与批量读取 | 用小型图片库理解“样本、标签、训练/测试” |
| 卷积层 | 解释局部感受野和卷积计算 | 用边缘检测小实验观察局部特征 |
| 池化层 | 降低空间尺寸、增强稳定性 | 用缩略图和模糊图解释“不必记住每个像素” |
| LeNet | 经典 CNN 结构 | 画出从图片到类别的流水线 |
| 图像增强 | 通过变换提高泛化 | 观察旋转、裁剪、亮度变化对检索的影响 |
| 微调 | 迁移预训练模型 | 社团扩展：用现成模型提取图像向量 |

## 为什么用“图像检索”而不是直接做分类

分类任务容易让学习者误以为 AI 只是“给图片贴标签”。图像检索更适合教学，因为它会自然暴露三个核心问题：

- 图片如何表示成向量。
- 两张图片为什么相似。
- 系统为什么会把不该相似的图片排在前面。

这些问题能把像素、特征、距离、卷积、向量数据库串成一条主线。

## 本章动手任务

打开 [`source-project/d2l-zh/chapters`](../source-project/d2l-zh/chapters/)，挑选任意两章完成阅读标注：

1. 标出一个可以直接做成课堂实验的概念。
2. 标出一个对高中学习者过难、需要降维处理的概念。
3. 写出一个“先观察现象，再引出术语”的讲法。

示例：

```text
先让学习者拖动图片亮度，观察检索结果变化。
再引出：颜色特征对光照很敏感，因此需要更稳定的特征。
```

这就是本书的基本改造方法：从现象出发，用项目承载概念。
