# 第 11 章：从课堂 demo 到视觉搜索项目

## 可选项目方向

### 校园图标检索

收集活动图标、社团 logo、班级海报元素，做一个按颜色、风格和用途检索的素材库。

### 实验室安全图片检索

收集安全标识、设备图片和操作场景，做“看图找规则”的学习工具。

### 阅读海报素材推荐

给定一本书的主题词，检索适合的背景图、图标和配色方案。

## 工程边界

展示项目时要明确：

- 数据来源是否合规；
- 图片是否涉及肖像或隐私；
- 检索结果是否需要人工筛选；
- 系统是否只是辅助，而不是最终判断。

## 项目分工

| 角色 | 任务 |
| --- | --- |
| 数据组 | 收集图片和标签 |
| 表示组 | 设计特征或 embedding |
| 检索组 | 实现相似度和排序 |
| 评测组 | 设计查询和 badcase |
| 展示组 | 组织演示和说明文档 |
