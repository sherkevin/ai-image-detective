# 第 12 章：Capstone 图像检索作品集

## 最终提交物

完整项目应包含：

- 可运行网页；
- 图片或图形数据集；
- 特征设计说明；
- 相似度计算方法；
- 10 个测试查询；
- badcase 表；
- 项目展示脚本。

## 评分表

| 维度 | 说明 |
| --- | --- |
| 数据准备 | 图片来源清楚，标签一致 |
| 表示设计 | 能解释特征或向量含义 |
| 检索效果 | Top-K 排序可解释 |
| 误判分析 | 能从特征、权重、目标解释错误 |
| 项目边界 | 能说明隐私、版权和人工确认 |
| 展示表达 | 能讲清楚从图片到向量再到排序 |

## README 写法

图像检索项目的 README 可以按这个顺序写：

1. 项目目标；
2. 数据集说明；
3. 特征或 embedding 设计；
4. 交互页面截图；
5. 检索样例；
6. badcase 和下一步计划。

## 最终提醒

图像检索项目的价值不在于“模型很高级”，而在于能解释机器如何表示图片、如何排序、为什么出错、怎样改进。
