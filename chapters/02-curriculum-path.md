# 2. 高中化改造路线

本书把 D2L 中较完整的视觉模型知识，改造成一个可在高中课堂完成的“图像侦探”项目。项目不要求一开始训练大型模型，而是先把“图片变向量、向量做比较”讲清楚。

## 项目边界

本项目追求三件事：

- 能用清晰方式描述一张图片的特征。
- 能计算图片之间的相似度。
- 能解释检索结果的正确与错误。

这三个目标会自然引出深度学习，但不会被深度学习术语淹没。

## 四个渐进版本

| 版本 | 核心能力 | 可交付成果 |
| --- | --- | --- |
| V0 像素观察版 | 观察图片尺寸、颜色、灰度 | 图片观察记录 |
| V1 手工特征版 | 颜色直方图、边缘数量、纹理粗细 | 浏览器检索 Demo |
| V2 最近邻检索版 | 用距离函数排序相似图片 | 相似度矩阵和误判分析 |
| V3 深度特征版 | 使用 CNN / CLIP 特征做扩展 | 社团挑战版检索系统 |

## 每一课的固定节奏

1. 观察图片现象：让结果先可见。
2. 定义一个概念：像素、特征、向量、距离、卷积。
3. 修改一个实验参数：颜色权重、边缘权重、距离函数、数据增强。
4. 记录一次误判：说明系统为什么错，如何改。

## 评价方式

| 评价项 | 观察点 |
| --- | --- |
| 数据意识 | 图片库是否有类别、数量、来源和偏差记录 |
| 算法理解 | 是否能解释特征向量和距离函数 |
| 工程实现 | Demo 是否能稳定运行，交互是否清楚 |
| 误判分析 | 是否能把错误转化为改进方案 |

这样的课程更像真实 AI 项目：不是背概念，而是在一个可运行系统中反复观察、修改、解释。
