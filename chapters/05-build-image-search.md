# 第 5 章：动手做图像检索系统

## 项目结构

本章对应 [互动实验](https://sherkevin.github.io/ai-image-detective/labs/playground.html)。每个图形由三类信息组成：

```js
{
  id: "A",
  name: "红色圆形条纹",
  color: "red",
  shape: "circle",
  texture: "stripe",
  vector: [1,0,0,1,0,1,0]
}
```

## 实现步骤

1. 准备若干图形；
2. 给每个图形写特征向量；
3. 读取滑块权重；
4. 计算目标图形和候选图形的相似度；
5. 按分数排序；
6. 展示结果和分数条。

## 分层挑战

### 基础

新增一个“绿色三角形条纹”图形，并让它出现在排序中。

### 进阶

增加一个“大小”特征，观察大小权重如何影响排序。

### 挑战

加入“多样性”规则：如果前两个结果颜色相同，第三个结果优先选择不同颜色。

## 展示要求

展示时必须说明一次误判，并从特征、权重或任务目标三个角度解释原因。
