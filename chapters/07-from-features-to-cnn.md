# 第 7 章：从手工特征到 CNN 表示

## 为什么手工特征不够

前几章使用颜色、形状、纹理作为手工特征。这适合入门，但真实图片远比抽象图形复杂：一张校园活动照片可能包含人物、背景、文字、姿态、光线和遮挡。

深度学习中的 CNN 可以从大量图片中学习特征。它不是人工写出“圆形”“条纹”，而是逐层提取边缘、纹理、局部形状和更高级的视觉模式。

## 和 D2L 的关系

《动手学深度学习》的计算机视觉章节从图像增广、微调、目标检测等任务进入视觉模型。本项目不直接搬这些内容，而是把其中的主线改写为高中可理解的版本：

```text
像素 -> 局部特征 -> 图像向量 -> 相似度检索
```

## 课堂活动

给出三张图片：

1. 同一物体，不同光照；
2. 同一颜色，不同物体；
3. 同一形状，不同背景。

讨论：手工特征会在哪些情况下失败？

## 项目延伸

把交互实验里的手工向量替换成“模拟 CNN 向量”：不用真实训练模型，只提供几组预设 embedding，让课堂先观察模型表示和手工表示的差异。
