# 第 7 章：从手工特征到卷积表示

## 为什么手工特征不够

前几章使用颜色、形状、纹理作为手工特征。这适合入门，但真实图片远比抽象图形复杂：一张校园活动照片可能包含人物、背景、文字、姿态、光线和遮挡。

深度学习中的卷积神经网络可以从大量图片中学习特征。它不是人工写出“圆形”“条纹”，而是逐层提取边缘、纹理、局部形状和更高级的视觉模式。

## 从入门实验到深度视觉

深度视觉课程通常会从图像增广、微调、目标检测等任务进入视觉模型。本章只保留高中阶段最需要理解的一条线：

```text
像素 -> 局部特征 -> 图像向量 -> 相似度检索
```

## 课堂活动

给出三张图片：

1. 同一物体，不同光照；
2. 同一颜色，不同物体；
3. 同一形状，不同背景。

讨论：手工特征会在哪些情况下失败？

## 项目延伸

把交互实验里的手工向量替换成“模拟卷积向量”：不用真实训练模型，只提供几组预设向量，让课堂先观察模型表示和手工表示的差异。
