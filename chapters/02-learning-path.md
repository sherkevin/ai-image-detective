# 5. 课程项目路线

本课程围绕“图像侦探”逐步完成。每一阶段都产生一个可运行、可解释、可评价的项目产物。

## 四个版本

| 版本 | 核心能力 | 项目产物 |
| --- | --- | --- |
| V0 像素观察版 | 观察尺寸、颜色、灰度和边缘 | 图片观察记录 |
| V1 手工特征版 | 颜色直方图、形状、纹理、边缘 | 浏览器检索演示页 |
| V2 最近邻检索版 | 用距离函数排序相似图片 | 相似度矩阵和误判分析 |
| V3 深度特征版 | 使用卷积神经网络或图文对齐模型特征做扩展 | 社团挑战版检索系统 |

## 每一课的固定节奏

1. 观察图片现象：先让排序和误判可见。
2. 定义一个概念：像素、特征、向量、距离、卷积。
3. 修改一个实验参数：颜色权重、边缘权重、距离函数、数据增强。
4. 记录一次误判：说明系统为什么错，如何改。

## 结课作品要求

结课作品应包含四部分：可运行演示页、图片库、检索日志、误判分析报告。评价重点是能否解释模型行为，而不是只展示正确结果。
