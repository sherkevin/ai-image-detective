# 第 3 单元：传统视觉：边缘、轮廓与运动

## 为什么先学传统视觉

在进入深度学习之前，传统视觉可以帮助学习者理解图片不是神秘对象，而是可以被处理的数字矩阵。灰度、阈值、边缘、轮廓和运动检测都能直接观察。

## 常见任务

| 任务 | 作用 | 校园场景 |
| --- | --- | --- |
| 灰度转换 | 去掉颜色，只看明暗 | 观察文字和边缘 |
| 阈值分割 | 把像素分成前景和背景 | 提取黑白标识 |
| 边缘检测 | 找出变化明显的位置 | 识别图形轮廓 |
| 运动检测 | 比较连续画面差异 | 观察活动视频中的移动 |

## 课堂实验

选择一张校园标识图片，完成四步：

1. 转成灰度图；
2. 调整阈值；
3. 找出边缘；
4. 解释哪些信息被保留，哪些信息丢失。

## 误判讨论

传统视觉方法容易受光照、遮挡和背景影响。例如同一个标识在阴影下可能被识别成不同颜色；背景纹理太复杂时，边缘检测会出现很多噪声。

## 项目产出

把实验前后的图片、参数和观察记录放进项目档案。重点不是追求最好效果，而是说明图像处理参数如何改变结果。

## 深入理解：传统视觉强调可控处理

在深度学习广泛使用之前，许多视觉任务依靠传统图像处理完成。传统视觉方法通常把图片经过一系列可解释操作：灰度化、模糊、阈值分割、边缘检测、轮廓提取、形态学处理。每一步都有明确作用，也有明显局限。

传统视觉特别适合课堂，因为学习者能马上看见参数怎样改变结果。阈值调高，暗处细节可能消失；边缘检测太敏感，背景纹理会变成噪声；模糊过强，重要边界会被抹掉。这些现象比抽象讲模型更容易建立视觉直觉。

## 实验流程

| 步骤 | 目的 | 观察问题 |
| --- | --- | --- |
| 灰度化 | 去掉颜色，只看明暗 | 哪些信息丢失了 |
| 模糊 | 减少噪声 | 细节是否被抹掉 |
| 阈值分割 | 把图像分成前景和背景 | 阈值如何影响结果 |
| 边缘检测 | 找出变化剧烈的位置 | 背景是否产生噪声 |
| 轮廓提取 | 得到物体外形 | 轮廓是否完整 |

每一步都要求保存图片，这样项目档案中就能呈现算法过程，而不是只放最终结果。

## 动手实验：校园标识提取

选择一张校园标识或活动海报，尝试提取其中的主要图形。先用灰度图观察亮暗差异，再用不同阈值分割前景，最后用边缘检测观察轮廓。记录至少三组参数，并说明哪一组效果最好、为什么。

```text
参数记录：
阈值 80：保留较多背景噪声
阈值 130：主体较清楚，但文字变细
阈值 180：主体断裂，细节丢失
```

## 常见误区

第一种误区是把传统视觉和深度学习对立起来。实际上，传统视觉提供了大量可解释工具，在数据少、规则明确、环境可控的场景中仍然有价值。第二种误区是只展示最好参数，不展示参数变化。课程项目应该展示过程，因为参数选择本身就是学习内容。第三种误区是忽略环境变化。同一个算法在明亮照片和阴影照片上效果可能完全不同，这正是误判分析的切入点。
