# 第 7 单元：目标检测

## 分类和检测的区别

图像分类回答“图片里有什么”；目标检测还要回答“它在哪里”。目标检测需要输出类别和位置框。

## 核心概念

| 概念 | 说明 |
| --- | --- |
| 边界框 | 用矩形框标出目标位置 |
| 置信度 | 模型对检测结果的把握 |
| 交并比 | 预测框和真实框重合程度 |
| 非极大值抑制 | 去掉重复检测框 |

## 校园项目场景

目标检测可以用于：

- 识别实验室安全标识；
- 标出海报中的图标元素；
- 在活动照片中定位设备或物品；
- 做“看图找规则”的学习工具。

这些场景都需要注意隐私和肖像问题。课堂项目优先使用公开图片、图标和无个人身份信息的素材。

## 课堂任务

给 5 张图片手工标注边界框，并计算一个预测框和真实框的重合程度。讨论：

- 框画大一点还是小一点更好；
- 多个目标重叠时怎样处理；
- 为什么检测结果需要人工检查。

## 项目产出

形成一个小型标注集，包含图片、目标类别、边界框和误判说明。

## 深入理解：分类回答“是什么”，检测回答“在哪里”

图像分类只需要判断整张图属于哪一类；目标检测还要指出目标位置。对于校园图片，分类可能回答“这是一张实验室图片”，检测则要标出护目镜、试管、警示标识分别在哪里。检测任务更复杂，因为它同时包含类别判断和位置回归。

目标检测的第一步是标注边界框。边界框不是随便画一个矩形，而是要尽量贴合目标，同时保持标注规则一致。框画得太大，会包含过多背景；框画得太小，会丢失目标边缘。不同人标注不一致，会直接影响训练和评测。

## 检测评测：重合程度

可以用“交并比”理解预测框和真实框的重合程度：

```text
交并比 = 两个框重叠面积 / 两个框覆盖总面积
```

如果预测框和真实框重叠很多，交并比接近 1；如果几乎没有重叠，接近 0。课堂上可以用方格纸手算一次，让学习者看到检测评测不是凭感觉判断。

## 常见检测错误

| 错误类型 | 示例 | 可能原因 |
| --- | --- | --- |
| 漏检 | 图片里有护目镜但没有框出 | 目标太小或被遮挡 |
| 误检 | 把普通圆形物体当成警示标志 | 形状相似、背景干扰 |
| 框不准 | 框住了目标和大量背景 | 标注不一致、模型定位弱 |
| 类别错 | 把试管标成烧杯 | 类别定义不清或样例不足 |

## 项目加厚任务

在作品集中加入一个小型标注说明：图片数量、类别定义、边界框规则、标注样例、常见争议。即使不训练完整检测模型，只要能清楚说明标注和评测方法，也能体现对视觉项目全流程的理解。
