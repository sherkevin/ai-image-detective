# 第 9 单元：数据集、标注与评价指标

## 没有数据集，就没有评价

图像检索项目不能只展示几张成功图片。必须准备查询、期望结果和误判记录。否则“效果好”只是一种感觉。

## 最小测试集

| 查询 | 期望结果 | 评价点 |
| --- | --- | --- |
| 红色圆形 | 红色圆形图标 | 颜色和形状 |
| 蓝色条纹 | 蓝色条纹图形 | 颜色和纹理 |
| 实验室安全 | 安全标识或设备规范图 | 语义匹配 |
| 读书节海报 | 与阅读、书籍有关的素材 | 风格和主题 |

## 评价指标

| 指标 | 含义 |
| --- | --- |
| 前 K 个命中率 | 正确结果是否出现在前 K 个中 |
| 第一名准确率 | 第一名是否就是期望结果 |
| 多样性 | 返回结果是否过于单一 |
| 误判可解释性 | 能否说明为什么错 |

## 失败案例库

每个失败案例至少记录：

- 查询；
- 错误结果；
- 期望结果；
- 错误原因；
- 下一步改进。

## 项目产出

最终作品集中必须出现测试集和失败案例库。它们比“展示几张漂亮截图”更能体现课程设计能力。

## 深入理解：没有数据集，就没有可评价的视觉项目

视觉项目最容易被忽视的是数据集。很多演示看起来很顺畅，是因为只挑了几张容易成功的图片。一旦换成光照不同、角度不同、背景复杂或类别模糊的图片，系统就会暴露问题。因此，课程项目必须建立小而清楚的数据集，并用固定测试方式评价。

数据集不一定大，但必须有规则。图片来源是否允许公开展示，类别怎样定义，标注由谁完成，训练集和测试集是否分开，失败样例是否保留，这些问题决定了项目是否可信。

## 数据集说明模板

| 字段 | 内容 |
| --- | --- |
| 数据主题 | 校园标识、实验器材、活动海报等 |
| 图片数量 | 总数、每类数量 |
| 来源说明 | 自行拍摄、公开许可、自绘图形 |
| 类别定义 | 每个类别的判定规则 |
| 划分方式 | 训练集、验证集、测试集 |
| 隐私检查 | 是否包含人脸、姓名、联系方式 |

## 评价指标

不同任务使用不同指标。分类任务可以看准确率、混淆矩阵；检索任务可以看前几名命中率；检测任务可以看边界框重合程度和平均精度。高中课程中不必一次讲完所有公式，但要让学习者理解：指标必须和任务对应。

例如图像检索可以使用“前三名是否包含正确结果”。如果目标图是一张蓝色校徽，系统返回前三张中有一张正确校徽，就记为成功；如果前三张都是蓝色背景但不是校徽，就记为失败。这样的指标简单，但足以支持课堂比较。

## 项目加厚任务

本单元结束时，作品集中应出现两个表：数据集说明表和失败案例表。失败案例表必须写出图片、查询、错误结果、期望结果、错误原因和下一步改进。视觉项目的成熟度，很大程度上体现在能不能正视这些不漂亮的样例。
