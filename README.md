# 图像侦探：计算机视觉项目课

这是一套面向高中人工智能课程、科创社团和校本项目的计算机视觉教材。课程围绕一个清晰作品展开：做出一个能够描述图片特征、计算相似度、检索相近图像，并解释误判原因的“图像侦探”系统。

本书先用颜色、形状、纹理等可观察特征建立直觉，再逐步进入像素、向量、卷积、迁移学习、目标检测和图像检索。它强调“看见算法如何工作”，而不是把视觉模型包装成不可解释的黑箱。

## 课程主线

| 模块 | 章节 | 核心问题 | 项目产出 |
| --- | --- | --- | --- |
| 教材主体 | 10 个深度单元 | 像素、感知机、传统视觉、卷积、迁移学习、检测、图文检索、评价与部署 | 完整中文课程正文 |
| 项目路径 | 12 个课堂章节 | 怎样把知识落到图像检索项目 | 项目任务、实验、评价量规 |
| 教师资源包 | 代码、笔记本、原始许可 | 怎样继续阅读和运行更完整的工程材料 | 备课材料和进阶代码 |

## 最终作品

结课作品是一份可以打开、可以演示、可以解释的项目档案，至少包含：

- 一个可运行的图像检索页面；
- 一组图片或图形数据集；
- 一套特征表示和相似度计算方法；
- 十个检索查询和对应结果；
- 误判案例、原因分析和改进记录；
- 一份课堂展示脚本。
