# AI Image Detective：图像检索与视觉智能项目课

这是一套面向高中人工智能课程、信息科技拓展课与科创社团的项目式教材。课程围绕一个完整作品展开：**让计算机把图片表示成特征向量，并用相似度检索、误判分析和模型解释完成图像侦探任务**。

## 课程主线

本书只解决一个核心问题：**计算机怎样把一张图片变成可以比较、检索和解释的向量**。

学习者会完成一个“图像侦探”项目：给定一张目标图片，系统在图片库中寻找相似图片，解释相似度来自颜色、形状、纹理、边缘还是深度特征，并记录误判案例。课程从像素和手工特征开始，逐步过渡到卷积神经网络、迁移学习和多模态检索。

## 教材结构

| 编 | 主题 | 核心产出 |
| --- | --- | --- |
| 第一编：视觉系统地图 | 像素、特征、向量、距离 | 图像表示卡片 |
| 第二编：图像检索实验 | 颜色直方图、边缘、纹理、最近邻 | 可解释检索 Demo |
| 第三编：深度视觉模型 | 卷积、池化、LeNet、数据增强、迁移学习 | 模型结构图与实验报告 |
| 第四编：项目工程化 | 图片库、标注、指标、误判分析 | 图像侦探作品 |
| 第五编：科创拓展 | CLIP、多模态、图像向量数据库 | 社团挑战版方案 |

## 互动实验室

[图像检索实验室](https://sherkevin.github.io/ai-image-detective/labs/playground.html) 支持四类课堂操作：

- 选择不同目标图形，观察最近邻排序变化。
- 调节颜色、形状、纹理、边缘和深度特征权重。
- 查看特征向量、距离贡献和误判原因。
- 记录一次检索失败，并提出数据或模型改进方案。
