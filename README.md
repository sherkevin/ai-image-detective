# AI Image Detective：给高中生的图像检索与向量课

这是一套面向高中人工智能入门、信息技术拓展课和科创社团的开源教材。它用一个完整项目贯穿全书：

> 做一个“图像侦探”检索系统，让学生理解机器怎样把图片变成数字，并用相似度找到相近图片。

在线阅读与互动实验：<https://sherkevin.github.io/ai-image-detective/>

## 这本书解决什么问题

学生常听到“多模态 AI”“图像理解”“推荐系统”，但这些词如果只停留在概念层面，很难进入真实理解。本书把图像检索拆成高中生可观察、可调参、可解释的流程：

1. 图片可以被表示成一组特征；
2. 特征可以组成向量；
3. 向量之间可以计算相似度；
4. 最近邻检索会产生排序；
5. 排序错误可以通过任务目标、特征和权重来分析。

## 课程产出

学生完成后应能做出一个可运行的图像检索原型，并能解释：

- 为什么机器看到的不是“图片本身”，而是数字表示；
- 颜色、形状、纹理等特征如何影响检索；
- “相似”不是绝对判断，而是和任务目标有关；
- 如何用误判样例改进特征或权重。

## 教材结构

- 第 0 章：课程地图与项目成品
- 第 1 章：机器怎样“看见”图片
- 第 2 章：特征、向量与表示
- 第 3 章：相似度与距离
- 第 4 章：最近邻检索与排序
- 第 5 章：动手做图像检索系统
- 第 6 章：误判分析、推荐系统与课堂延伸
