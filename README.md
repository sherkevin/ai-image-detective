# AI Image Detective

面向高中人工智能入门课的互动课程项目：学生通过一个“图像侦探”小游戏理解特征向量、相似度和最近邻检索。

项目不调用外部模型。网页用可见的颜色、形状、纹理等特征模拟图像向量，让学生能直接观察权重变化如何影响检索结果。

## 课程主线

一个问题贯穿全课：

> 机器怎样判断两张图片“相似”？

学生会依次完成：

1. 选择一张目标图片；
2. 调节颜色、形状、纹理权重；
3. 观察相似度排序变化；
4. 解释误判原因；
5. 修改权重，让检索更符合任务目标。

## 项目边界

这是课程原型。网页中的“图片”是抽象图形，特征向量也是教学用简化表示，不等同于真实视觉模型。
